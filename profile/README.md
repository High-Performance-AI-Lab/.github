# High Performance AI Lab

Open inference systems for hardware you own — an engine, a cache format,
a dashboard, and the book that explains how they work.

**Website:** [high-performance-ai-lab.github.io](https://high-performance-ai-lab.github.io) ·
**Book:** [How to Write an Inference Engine](https://high-performance-ai-lab.github.io/muser-book/)

| Project | What it is |
|---|---|
| [muser](https://github.com/High-Performance-AI-Lab/muser) | Standalone Muse Glimmer (~30B) inference engine: Apple Silicon Metal decode, a kquant DFlash speculative lane, and disaggregated NVFP4 prefill handed off from a GB10 node |
| [kvpack](https://github.com/High-Performance-AI-Lab/kvpack) | Crash-safe, bitwise-exact KV-cache replay: save inference state once, restore it bit-identically across processes, crashes, and machines |
| [muser-console](https://github.com/High-Performance-AI-Lab/muser-console) | Live dashboard for muser engines — fleet health, cache savings, sessions, gap-preserving history |
| [muser-book](https://github.com/High-Performance-AI-Lab/muser-book) | *How to Write an Inference Engine* — the forty-chapter, receipt-cited book, [free to read online](https://high-performance-ai-lab.github.io/muser-book/) |

Measured numbers cite receipts, fail-closed checks stay closed, and no
number is rounded into existence.
